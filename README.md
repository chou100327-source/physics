# 物理上學期重點整理（高職一年級）

Physics study notes for Taiwanese vocational high school students (高職 / 技高).

**線上閱讀：https://physics-mu-26cb.vercel.app**

## 內容

| 章 | 單元 |
|---|---|
| 1 緒論 | 物理學發展史、國際單位系統（SI、字首、有效數字） |
| 2 直線運動 | 與運動有關的物理量、加速度與等加速度運動、自由落體、實驗：加速度的量測 |
| 3 平面運動 | 平面上的向量、等速圓周運動、實驗：旋轉起重機 |

## 特色

- 每個公式：**上面是中文名稱、下面是單位**，除法寫成上下分數，方便背誦
- 每節附陷阱提醒與例題
- 最後有「公式總表」，標示每條公式出自哪一個單元
- 淺色／深色模式切換；在空白背景連點兩下，回到最上面的目錄
- 手機、平板、電腦都能閱讀
