02

直線運動

2-1與運動有關的物理量

Δx位移 = x₂末位置 − x₁初位置 v̄平均速度 = Δx位移 / Δt經過時間 平均速率 = s路徑長 / Δt經過時間 等速度：x位置 = x₀初位置 + v速度 t時間
物理量向量 / 純量說明
位置 x向量相對於原點的位置，有正負
位移 Δx向量末位置 − 初位置，只看起點和終點
路徑長（路程）s純量實際走過的長度，一定 ≥ 0
平均速度 v̄向量位移 ÷ 時間
平均速率純量路徑長 ÷ 時間
瞬時速度 v向量某一瞬間的速度＝ x–t 圖切線斜率
  • |位移| ≤ 路徑長，只有單方向直線前進時兩者相等。
  • 繞一圈回到原點：位移 = 0、平均速度 = 0，但路徑長和平均速率不是 0。
  • 等速度運動：x–t 圖是斜直線（斜率 = 速度），v–t 圖是水平線（面積 = 位移）。
例題

從 x = 0 往東走 40 m，再往西走 10 m，共花 10 s。位移 = +30 m，路徑長 = 50 m；v̄平均速度 = 30 / 10 = 3 m/s（向東），平均速率 = 50 / 10 = 5 m/s。

2-2加速度與等加速度運動

a加速度 = Δv速度變化 / Δt經過時間 = (v末速度 − v₀初速度) / t時間

等加速度四大公式（缺哪個量，就選沒有它的那條）

公式題目沒給
① v末速度 = v₀初速度 + a加速度 t時間位移 Δx
② Δx位移 = v₀初速度 t時間 + ½ a加速度 t時間²末速度 v
③ v末速度² = v₀初速度² + 2 a加速度 Δx位移時間 t
④ Δx位移 = (v₀初速度 + v末速度) / 2 × t時間加速度 a
x–t 圖：拋物線，切線斜率 = 瞬時速度
v–t 圖：斜直線，斜率 = 加速度，面積 = 位移
a–t 圖：水平線，面積 = 速度變化 Δv
  • 加速度和速度同方向 → 越來越快；反方向 → 越來越慢（減速）。
  • 加速度是負的，不一定代表變慢，要看它和速度方向是否相反。
  • 由靜止開始等加速度：每一段相等時間的位移比 = 1 : 3 : 5 : 7 …；累計位移比 = 1 : 4 : 9 : 16 …
例題

汽車以 20 m/s 行駛，煞車加速度 −5 m/s²。停下時間：t時間 = (0 − 20) / (−5) = 4 s；煞車距離：0 = 20² + 2(−5)Δx位移，Δx = 40 m。

陷阱

代公式前先定好正方向，和它相反的速度、加速度都要帶負號。速度加倍，煞車距離變 4 倍（因為 Δx ∝ v₀²）。

2-3自由落體

v速度 = g重力加速度 t時間 h落下高度 = ½ g重力加速度 t時間² v速度² = 2 g重力加速度 h落下高度 g重力加速度 ≈ 9.8 m/s²（常取 10）
  • 自由落體 = 初速 0、加速度 g 向下的等加速度運動。
  • 忽略空氣阻力時，落下快慢和質量無關，羽毛和鐵球一起落地（伽利略推翻亞里斯多德）。
  • 每秒速度增加約 10 m/s；第 1、2、3 秒內落下距離比 1 : 3 : 5。

延伸：鉛直上拋（向上為正，加速度 = −g）

v速度 = v₀初速度 − g重力加速度 t時間 上升時間 t時間 = v₀初速度 / g重力加速度 最大高度 H最大高度 = v₀初速度² / 2g重力加速度
  • 最高點：速度 = 0，但加速度仍是 g（向下）。
  • 上升時間 = 下降時間；落回原處時速率 = 拋出速率，方向相反。
例題

物體從 20 m 高處自由落下（g = 10）：20 = ½ × 10 × t時間²，t = 2 s；落地速度 v速度 = g重力加速度 t時間 = 10 × 2 = 20 m/s。

陷阱

高度變 4 倍，落地時間只變 2 倍（t ∝ √h）。

實驗加速度的量測

T打點週期 = 1 / f頻率 a加速度 = (s₂第二段位移 − s₁第一段位移) / T每段時間²
  • 用打點計時器（或光電閘）記錄物體在相等時間間隔的位置。
  • 點距相等 → 等速度；點距越來越大 → 加速；越來越小 → 減速。
  • 等加速度運動中，連續相等時間內的位移差是定值：Δs = aT²。
  • 也可以算出每段的平均速度，畫 v–t 圖，斜率就是加速度。
例題

每段時間 0.1 s，連續兩段位移 2.0 cm、3.0 cm：a加速度 = (0.030 − 0.020) / 0.1² = 1.0 m/s²。

平面運動

3-1平面上的向量

Axx分量 = A向量大小 cosθ夾角 Ayy分量 = A向量大小 sinθ夾角 A向量大小 = √(Axx分量² + Ayy分量²) tanθ夾角 = Ayy分量 / Axx分量
比較純量向量
定義只有大小有大小，也有方向
例子路徑長、速率、時間、質量、溫度、能量位移、速度、加速度、力
向量相加做法
三角形法A 的尾端接 B 的起點（頭尾相接），從 A 起點畫到 B 尾端就是合向量
平行四邊形法兩向量起點放在一起，畫平行四邊形，對角線就是合向量
分量法先拆成 x、y 分量，x 加 x、y 加 y，再合起來
|A向量A − B向量B| ≤ R合向量 ≤ A向量A + B向量B 互相垂直：R合向量 = √(A向量A² + B向量B²)
角度 θ30°37°45°53°60°
sin θ1/20.6√2/20.8√3/2
cos θ√3/20.8√2/20.61/2
三邊比30°–60°–90° = 1 : √3 : 2；3 : 4 : 5（37°、53°）45°–45°–90° = 1 : 1 : √2
  • 兩向量同方向，合向量最大（A + B）；反方向，合向量最小（|A − B|）。
  • 渡河問題：船的合速度 = 船速 + 水速（向量相加）。船頭垂直河岸時，渡河時間最短：t時間 = d河寬 / v船船速。
例題

向東走 3 m、再向北走 4 m：位移大小 R合向量 = √(3² + 4²) = 5 m，方向東偏北 53°；路徑長 = 7 m。

陷阱

向量不能直接把大小相加（3 + 4 ≠ 5）；只有同方向時才能直接相加。

3-2等速圓周運動

f頻率 = 1 / T週期 v速率 = 2πr半徑 / T週期 = 2πr半徑f頻率 ω角速度 = 2π / T週期 = 2πf頻率 v速率 = r半徑 ω角速度 ac向心加速度 = v速率² / r半徑 = r半徑ω角速度² = 4π²r半徑 / T週期² Fc向心力 = m質量 v速率² / r半徑
物理量單位說明
週期 Ts轉一圈所需的時間
頻率 fHz（次/秒）每秒轉幾圈；轉速 rpm ÷ 60 = f
速率 vm/s大小不變，方向沿切線一直改變
角速度 ωrad/s每秒轉過的角度；一圈 = 360° = 2π rad
向心加速度 acm/s²大小不變，方向永遠指向圓心
  • 等速圓周運動「等速」指的是速率不變；速度方向一直在變，所以有加速度，不是等速度運動。
  • 速度方向（切線）和向心加速度方向（指向圓心）互相垂直。
  • 繩子突然斷掉，物體沿切線方向飛出去。
  • 同一個轉盤上各點的 T、f、ω 相同；半徑越大，v 越大。
例題

半徑 2 m、週期 π 秒：v速率 = 2π × 2 / π = 4 m/s，ac向心加速度 = 4² / 2 = 8 m/s²。

陷阱

半徑固定時，速率變 2 倍，向心加速度變 4 倍（ac ∝ v²）。轉速單位 rpm 是「每分鐘」轉數，要先除以 60。

實驗旋轉起重機

向心力 Fc向心力 = 懸掛重物的重量 M重物質量g重力加速度 M重物質量g重力加速度 = m旋轉物質量 × 4π²r旋轉半徑 / T週期²
  • 手握管子讓上方小物體做水平圓周運動，繩子穿過管子下方掛重物；轉速適當時重物剛好被「吊起」而不上下移動。
  • 此時繩子張力 = 重物重量，這個張力提供旋轉物體的向心力。
  • 重物越重（向心力越大）→ 要轉得越快（週期越短）才能吊住。
  • 半徑越大、向心力不變 → 週期要變長。量週期時通常測 10 圈再除以 10，減少誤差。
